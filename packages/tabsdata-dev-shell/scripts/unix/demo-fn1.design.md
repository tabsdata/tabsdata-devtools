# demo-fn1

A sample shell command: prints its own name plus a detail fetched through two external binaries
(`whoami`/`hostname`), so the `bin-reqs` machinery -- declaration, `tdd --reqs`, the pre-run refusal -- is
exercised end to end. Registered `--demo`: out of `tdd help` unless `--demo`, otherwise a
command like any other. Copy it to start a new shell command.
